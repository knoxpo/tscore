Snapshot from 2026-09-03, Apple M5 Max (18 logical CPUs, 6P + 12E), tscore 0.1.0, Node 24.17.0, Bun 1.4.0. Steady-state cells are the median of 5 runs after a discarded warm-up. Ratios are engine ÷ Node; lower is better. The live file is [benchmarks/compare/RESULTS.md](https://github.com/knoxpo/typescript-core/blob/main/benchmarks/compare/RESULTS.md).

## Startup and parse

| benchmark | tscore | node | bun |
|---|---|---|---|
| startup (hello.ts) | **1.6 ms** (0.04×) | 36.6 ms | 4.3 ms (0.12×) |
| parse + compile (~50k LOC) | **7.4 ms** (0.08×) | 97.4 ms | 11.2 ms (0.11×) |

## Steady state, shared sources

| benchmark | tscore | node | bun |
|---|---|---|---|
| objects | 111.0 (4.65×) | 23.9 | **23.1** (0.97×) |
| closures | 103.3 (3.07×) | **33.6** | 49.4 (1.47×) |
| alloc | 132.5 (3.10×) | **42.7** | 48.6 (1.14×) |
| gc_churn | 192.3 (3.83×) | 50.2 | **42.0** (0.84×) |
| promises | 62.4 (0.99×) | 63.0 | **58.1** (0.92×) |

Single-core object-heavy code is where the interpreter and Tier-1 still lose to a mature JIT. This is the known wall; see the [architecture](/docs/architecture/overview) for what the JIT does and does not yet do.
