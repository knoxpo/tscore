Snapshot from 2026-09-06, Apple M5 Max (18 logical CPUs, 6P + 12E), tscore 0.1.0, Node 24.17.0, Bun 1.4.0. Steady-state cells are the median of 5 runs after a discarded warm-up. Ratios are engine ÷ Node; lower is better. The live file is [benchmarks/compare/RESULTS.md](https://github.com/knoxpo/typescript-core/blob/main/benchmarks/compare/RESULTS.md).

## Startup and parse

| benchmark | tscore | node | bun |
|---|---|---|---|
| startup (hello.ts) | **2.1 ms** (0.05×) | 39.9 ms | 5.7 ms (0.14×) |
| parse + compile (~50k LOC) | **8.3 ms** (0.08×) | 104.5 ms | 13.1 ms (0.13×) |

## Steady state, shared sources

| benchmark | tscore | node | bun |
|---|---|---|---|
| objects | 105.7 (3.91×) | 27.0 | **24.2** (0.89×) |
| closures | 107.6 (2.77×) | **38.8** | 51.0 (1.31×) |
| alloc | 118.0 (2.66×) | **44.4** | 48.9 (1.10×) |
| gc_churn | 210.5 (3.49×) | 60.3 | **48.4** (0.80×) |
| promises | 65.0 (0.96×) | 67.6 | **63.5** (0.94×) |

Single-core object-heavy code is where the interpreter and Tier-1 still lose to a mature JIT. This is the known wall; see [Compared to V8 and JSC](/docs/architecture/vs-v8-jsc) for what the JIT does and does not yet do.
